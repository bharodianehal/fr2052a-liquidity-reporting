# AI/BI dashboards (as deployed)

The two Lakeview dashboards of the build, exported from the workspace (`GET /api/2.0/lakeview/dashboards/<id>`, `serialized_dashboard`).
Generated by `deploy/dashboard.py` (catalog-free queries) and deployed by the platform bundle (`resources/dashboards.yml` sets the
catalog and the warehouse and publishes them with embed credentials). They read Delta through the SQL warehouse and are embedded in the app.

| File | Dashboard |
|---|---|
| `fr2052a_liquidity_reporting.lvdash.json` | FR 2052a Liquidity Reporting - source to report, data quality, rule coverage and validation, FR 2052a tables, adjustments |
| `fr2052a_lcr.lvdash.json` | FR 2052a LCR - LCR, HQLA, net cash outflows per entity and day |
